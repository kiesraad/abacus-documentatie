O 7: Proces-verbaal van een hoofdstembureau

## Welke data zet Abacus in dit proces-verbaal voor het HSB?

| element   | ingevuld door Abacus                                    |
|-----------|---------------------------------------------------------|
| titelblad | ja (informatie kieskring en verkiezing)       |
| header    | ja (informatie kieskring)                     |
| footer    | ja (modelnaam, hash EML_NL 510c)        |
