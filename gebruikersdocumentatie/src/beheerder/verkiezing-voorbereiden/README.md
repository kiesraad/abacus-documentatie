# Verkiezing toevoegen en beheren

Nu kun je een verkiezing toevoegen. Abacus leidt je door een wizard waarin je de bestanden toevoegt en aanvullende gegevens invult.

## Benodigdheden

Verzamel de gegevens die je nodig hebt om een verkiezing toe te voegen.

- Zorg dat je de EML-bestanden met de verkiezingsdefinitie (EML 110a) en kandidatenlijsten (EML 230b) hebt.
- Voor het gemeentelijk stembureau gebruik je (optioneel) ook het EML-bestand met de stembureaus (EML 110b). Dit bestand wordt gegenereerd door de gemeente.
- Als het aantal kiesgerechtigden in de gemeente niet in de EML 110b staat, zorg dan ook dat je dit aantal weet te vinden.
